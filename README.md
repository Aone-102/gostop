# 🎴 정통 맞고 (Go-Stop) - AI & PeerJS P2P 멀티플레이어

웹 브라우저에서 바로 즐길 수 있는 프리미엄 디자인의 **2인 맞고(고스톱)** 게임입니다.

---

## 🌟 주요 기능

1. **정교한 화투패 그래픽 & 손맛 타격감 사운드**
   - 1월(송학)부터 12월(비)까지 총 48장의 정통 화투패 SVG 렌더링
   - Web Audio API 기반의 경쾌한 화투 패 치는 소리("착!"), 셔플, 징, 고/스톱 효과음 내장

2. **완벽한 맞고 룰 엔진 (Rules Engine)**
   - 광(3광, 비3광, 4광, 5광), 열끗, 고도리, 멍텅구리(멍따 x2)
   - 띠(홍단, 청단, 초단, 일반 띠)
   - 피(10장부터 1점, 쌍피, 9월 국진 술잔 쌍피)
   - 뻑(설사), 쪽, 따닥, 싹쓸이 시 상대 피 뺏기
   - 7점 이상 달성 시 **고(GO) / 스톱(STOP)** 선택
   - 피박, 광박, 고박(독박) 배판 계산 및 승리 결산

3. **스마트 AI 대전 모드 (1인 플레이)**
   - 점수 가치(광 > 고도리 > 단/쌍피 > 피) 기반 최적 카드 선택
   - 상대방 점수 및 남은 패를 분석하여 승리 확률 높은 고/스톱 판단

4. **PeerJS P2P 실시간 2인 멀티플레이어**
   - **방 만들기**: 방 코드 생성 후 친구에게 공유
   - **참가하기**: 친구의 방 코드를 입력하여 P2P DataChannel로 다이렉트 연결
   - 기본적으로 무료 공용 PeerJS 클라우드(`0.peerjs.com`)를 사용하여 별도 서버 없이도 즉시 작동!
   - 자체/로컬 PeerJS 서버를 운영할 수 있는 옵션 및 `server.js` 제공

---

## 🚀 실행 방법

### 방법 1. 파이썬으로 즉시 실행 (가장 추천)
```bash
python serve.py
```
브라우저에서 **`http://localhost:8080`** 접속

### 방법 2. Node.js 및 로컬 PeerJS 서버 구동 (Node.js 설치 시)
```bash
npm install
npm start
```
- 브라우저 게임: `http://localhost:9000`
- 로컬 PeerJS 서버: `ws://localhost:9000`
